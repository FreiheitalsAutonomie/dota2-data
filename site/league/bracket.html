使用说明

本届使用 M1–M14 固定赛制；管理员发布后所有人可查看。

1. 填写战队

点击「战队设置」，或直接点击分组赛中的队名，填写 A1–A4、B1–B4 对应的 8 支战队。队标为可选项。名称留空时保留席位编号。

2. 录入赛果

点击比赛卡片，选择获胜战队并保存；比分可留空，也可只保存尚未结束的比分。上游赛果确定后，下游的胜者、负者席位自动替换为真实战队。修改已有胜负时，系统会提示清除受影响的下游赛果，避免出现错误对阵。

3. 阅读晋级关系

图中黑色连线仅表示胜者晋级。分组赛分流和胜者组负者落位写在卡片底部，后续卡片也会标注参赛来源。交叉落位严格使用 M5 负者 → M11、M6 负者 → M10；M7 负者进入 M13。仅分组赛预设 BO1，其他场次不擅自添加赛制，总决赛不额外增加重置赛。

4. 保存和分享

修改暂存在当前页面，点击平台上方「发布赛程」后统一保存。离开前请发布或导出 JSON 备份。PNG 与 SVG 可用于发群，镜像站会在下一次同步后更新。

5. 演示

「演示模式」隐藏编辑工具。按 Esc 返回编辑；导出的 PNG / SVG 不包含工具栏。超长队名在图中自动省略，可悬停或打开比赛卡片查看全称。
